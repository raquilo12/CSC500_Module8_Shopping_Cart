# CSC500_Module8_Shopping_Cart
CSC500 Module 8 Final Portfolio Project – DFW Hospital IT Equipment Shopping Cart
CSC500 Module 8 – DFW Hospital IT Equipment Shopping Cart

Project Overview

This project was developed for the Module 8 Final Portfolio Project in CSC500: Principles of Programming at Colorado State University Global.

The application is a Python shopping cart program designed to manage hospital IT equipment requests.

Program Features

Uses ItemToPurchase and ShoppingCart classes.

Adds equipment items to a shopping cart.

Removes existing items.

Modifies item quantities.

Displays item descriptions.

Calculates total quantities and costs.

Handles invalid menu selections and numeric input.

Supports case-insensitive item-name matching.

Repeats the menu until the user chooses to quit.

Technologies Used

Python 3.14

Running the Program

Download the Python source file.

Open the file in Visual Studio Code.

Follow the menu prompts.
